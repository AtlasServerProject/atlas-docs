# v1.29.3 — Comando `/fly`

Data: 2026-07-14

## Resumo

Adicionado comando `/fly` para alternar voo.

## Permissão

Podem usar:

- VIP;
- VIP+;
- VIP++;
- SUP;
- MOD;
- ADM;
- DONO.

Também foi mantida a permissão técnica:

```text
atlas.fly
```

Ela permite liberar o comando por permissão no futuro sem alterar código.

## Comando

```text
/fly
```

Comportamento:

- se o voo estiver desligado, ativa;
- se o voo estiver ligado, desativa;
- exige jogador autenticado;
- ao desativar fora do criativo/espectador, o jogador deixa de voar imediatamente.
