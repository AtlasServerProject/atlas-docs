# v1.29.2 — Comando `/back`

Data: 2026-07-14

## Resumo

Adicionado comando `/back` para retornar à última localização salva antes de teleportes manuais.

## Mudanças

- Novo comando:

```text
/back
```

- O jogador precisa estar autenticado.
- O Atlas salva a localização antes de:
  - `/lobby emerald`;
  - `/spawn`;
  - `/home`;
  - `/claimtp`;
  - `/rtp`.
- Ao executar `/back`, o jogador retorna para a última localização.
- O comando funciona como troca de posição:
  - ao voltar, a posição atual vira o novo destino de `/back`.

## Exemplo

Fluxo esperado:

```text
Survival Emerald
  ↓ /lobby emerald
Lobby Emerald
  ↓ /back
Volta ao ponto anterior no Survival Emerald
```

## Observações

- A primeira entrega mantém o histórico em memória durante a sessão do servidor.
- O Auth Lobby não é salvo como destino de `/back`.
