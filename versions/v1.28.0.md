# v1.28.0 — Sprint 9: Moderação e punições

## Objetivo

Iniciar a Sprint 9 com uma base própria de moderação para o Atlas, sem depender de plugin externo de punições.

## Comandos adicionados

- `/warn <jogador> <motivo>`
- `/kick <jogador> <motivo>`
- `/mute <jogador> <tempo|perma> <motivo>`
- `/unmute <jogador> <motivo>`
- `/ban <jogador> <motivo>`
- `/unban <jogador> <motivo>`
- `/banip <ip|jogadorOnline> <motivo>`
- `/unbanip <ip> <motivo>`
- `/punishments <jogador>`

## Duração de mute

Formatos aceitos:

- `10m`
- `2h`
- `7d`
- `perma`

## Regras implementadas

- Apenas staff ou console podem usar os comandos.
- Staff não pode punir jogador com cargo igual ou superior.
- Jogador mutado não consegue falar no chat.
- Jogador banido é desconectado ao entrar.
- IP banido desconecta jogadores daquele IP ao entrar.
- Warn é privado para o jogador alvo.
- Kick/Ban/BanIP desconectam jogadores online imediatamente.
