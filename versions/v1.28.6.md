# v1.28.6 — Hotfix Z-A Mega

Data: 2026-07-13

## Resumo

Adicionado `zamega-fabric-1.7.1.jar` ao servidor para corrigir desconexão ao pegar algumas mega pedras em modo criativo.

## Problema

Ao colocar certas mega stones na mão, o jogador era desconectado com:

```text
Failed to decode packet 'serverbound/minecraft:set_creative_mode_slot'
```

## Causa provável

O cliente possuía itens do addon Z-A Mega, mas o servidor tinha apenas `mega_showdown`. Quando o cliente enviava o item pelo inventário criativo, o servidor não reconhecia o registro/componente do item e derrubava a conexão.

## Mudanças

- Instalado `zamega-fabric-1.7.1.jar` em `/opt/atlas/server/fabric/mods`.
- Criado pacote separado para instalação manual: `mods-zamega-hotfix-2026-07-13.tar.gz`.
- Criado backup antes da alteração:

```text
/opt/atlas/server/backups/mod-versions/mods-pre-zamega-hotfix-20260713-152237.tar.gz
```

## Validação pendente

Reiniciar o servidor e testar novamente as mega stones no inventário criativo.
