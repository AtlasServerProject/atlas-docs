# v1.28.9 — Chunky para Nether e The End

Data: 2026-07-13

## Resumo

Chunky foi reinstalado e configurado para pré-gerar as dimensões liberadas no `/rtp`: Nether e The End.

## Mudanças

- Instalado `Chunky-Fabric-1.4.23.jar`.
- Servidor reiniciado e validado com `103 mods`.
- Adicionados comandos ao `atlas-cli`:
  - `pregenerate-nether`;
  - `pregenerate-end`.
- Cada comando aceita:
  - `start`;
  - `status`;
  - `pause`;
  - `continue` / `resume`.
- `pregenerate-survival start` foi atualizado para a sintaxe nova do Chunky.

## Execução

Pré-geração do Nether iniciada e posteriormente finalizada/sem tarefa pendente no Chunky.

Seleção usada no Nether:

```text
World: minecraft:the_nether
Shape: square
Center: 0, 0
Radius: 6000
```

Pré-geração do The End iniciada depois do Nether:

```text
World: minecraft:the_end
Shape: square
Center: 0, 0
Radius: 6000
```

Status inicial observado do The End:

```text
Processed: 388 chunks (0,07%)
ETA: ~1h40
Rate: ~94 cps
```

Não executar Nether e The End ao mesmo tempo para evitar travamentos.

## Comandos úteis

```bash
atlas-cli pregenerate-nether status
atlas-cli pregenerate-nether pause
atlas-cli pregenerate-nether continue

atlas-cli pregenerate-end start
atlas-cli pregenerate-end status
```
