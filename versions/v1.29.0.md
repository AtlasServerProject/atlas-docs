# v1.29.0 — Interface de kits e kit diário

Data: 2026-07-14

## Resumo

Primeira entrega prática da Sprint 10: o Atlas agora possui uma interface de kits com o Kit Diário.

## Mudanças

- Adicionado comando `/kits`.
- `/kits` abre uma interface com os kits disponíveis.
- Adicionado Kit Diário.
- O Kit Diário entrega a `Pá de Claim do Atlas`.
- Cooldown do Kit Diário: 24 horas por jogador.
- Se o inventário estiver cheio, a pá é dropada aos pés do jogador.
- Mantido atalho direto:

```text
/kit diario
```

## Banco de dados

Adicionada migration:

```text
029_daily_kits.sql
```

Tabela criada:

```text
daily_kit_claims
```

Ela registra o último resgate de cada kit por jogador.
