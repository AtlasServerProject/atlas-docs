# Atlas Core v1.29.8

## Adicionado

- Chat colorido com códigos usando `&`.

## Quem pode usar

- VIP
- VIP ✦
- VIP ✦✦
- SUP
- MOD
- ADM
- DONO

Também é possível liberar por permissão técnica:

```text
atlas.chat.color
```

## Exemplos

```text
&cMensagem vermelha
&aMensagem verde
&eMensagem amarela
&lMensagem em negrito
&rVoltar para o padrão
```
