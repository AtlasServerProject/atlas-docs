# v1.27.7 — Hotfix de login e carregamento de chunks

## Objetivo

Corrigir o caso em que o jogador entrava no Auth Lobby, mas ficava no limbo com o céu carregado e sem o mapa aparecer.

## Diagnóstico

O problema não estava nas texturas/resource packs. O log do servidor mostrava:

- `Force-added player with duplicate UUID`
- `UUID of added entity already exists`
- erro no rastreamento de chunks ao receber pacote de movimento do cliente

Isso indicava conflito no ciclo de entrada do player, causado pelo teleporte imediato para o spawn durante o evento `JOIN`.

## Alterações

- O spawn do Auth Lobby agora é agendado para o tick seguinte do servidor.
- O teleporte pendente é cancelado se o jogador desconectar antes de ser aplicado.
- O serviço de spawn roda antes do bloqueio de movimento, evitando que o lock capture uma posição antiga ou instável.
- O teleporte ignora jogadores que já estão no spawn correto.

## Validação

- `./gradlew compileJava`
- `./gradlew build`
- `atlas-core.jar` do servidor substituído pelo build corrigido.
- Serviço `atlas` reiniciado com sucesso.
- Hash do jar em produção confirmado igual ao build local.
