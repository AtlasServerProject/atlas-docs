# Atlas Core v1.29.11 — WorldEdit para Dono e ADM

## Correção

- O filtro global de comandos agora reconhece explicitamente a sintaxe `//comando` do WorldEdit.
- OWNER/DONO e ADMIN/ADM continuam sendo os únicos cargos autorizados a usar WorldEdit.
- Jogadores comuns continuam bloqueados e recebem a mensagem de restrição.
- O alias `/wand` permanece disponível para entregar o machado de seleção autorizado.
