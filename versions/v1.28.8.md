# v1.28.8 — Interface do `/rtp` com Nether e The End

Data: 2026-07-13

## Resumo

O `/rtp` agora possui uma interface para escolher a dimensão de destino dentro da experiência Survival Emerald.

## Mudanças

- `/rtp` abre uma GUI com:
  - Overworld;
  - Nether;
  - The End.
- Adicionados atalhos:
  - `/rtp overworld`;
  - `/rtp nether`;
  - `/rtp end`.
- Cada dimensão possui fila própria de destinos seguros.
- Cooldown por cargo e cancelamento por movimento foram preservados.
- Nether e The End passam a herdar as regras PvE das áreas survival:
  - fome desativada;
  - dano de queda desativado;
  - proteção contra Void;
  - morte retorna ao Lobby Emerald.
- The End recebeu `distortion_world_sinnoh.ogg` como trilha.

## Observações

O Nether e The End continuam no mesmo servidor/mundo de Survival Emerald, sem virar lobbys ou servidores separados.
